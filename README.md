# Kampüs İntifada (Campus Intifada)

BTU Kampüsü Farkındalık Hareketi — Etkinliğin Dijital İkizi.  
**Vicdan · Hafıza · Aksiyon**

🌐 **Canlı Site (Production):** [https://kampus-intifada-rosy.vercel.app](https://kampus-intifada-rosy.vercel.app)

---

## 🚀 Başlangıç

Geliştirme sunucusunu yerel ortamda çalıştırmak için:

```bash
npm install
npm run dev
```

Tarayıcınızda [http://localhost:3000/tr](http://localhost:3000/tr) adresini açarak uygulamayı görüntüleyebilirsiniz.

---

## 🛠️ Teknolojiler

- **Framework:** Next.js (App Router)
- **Stil:** Tailwind CSS
- **Uluslararasılaşma (i18n):** next-intl (`/tr`, `/en`, `/ar`)
- **Animasyon:** Framer Motion
- **3D & Canvas:** Three.js / React Three Fiber & HTML5 Canvas (Nokta-Matris Dünya Haritası)
- **Veritabanı:** Supabase
- **Dağıtım (Deployment):** [Vercel](https://kampus-intifada-rosy.vercel.app)
